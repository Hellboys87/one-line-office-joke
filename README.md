A one-line office joke for make.fun's "One-Line Office Joke: 24-Hour Sprint" — the calendar is so packed that even lunch has been booked by HR and labelled "(optional)".

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-out node main.ts
```

This writes the joke (one line, 104 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output` when the variable is unset.
